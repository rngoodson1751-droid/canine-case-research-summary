# Retrospective canine case research summary

An identifier-minimised, preliminary single-case account using pseudonym **Canine case A**. Intended to organise observations and missing evidence for future veterinary review.

Read [the case summary](research/case-summary.md), [limitations](research/limitations.md), and [privacy policy](PRIVACY.md).

## Scope and status
The available evidence is owner recollection and relayed clinical findings. Original laboratory and formal imaging reports have not been reviewed. This is not a peer-reviewed study, verified clinical dataset or diagnostic conclusion. No treatment recommendations are provided.

## Structure
- `research/`: abstracted narrative and limitations.
- `methods/`: evidence definitions and data dictionary.
- `.github/`: publication checklist.
- `PRIVACY.md`: rules for keeping identifiable source material out.

The repository contains only reviewed text. No private charts, correspondence, images, videos or private source links are included. Public GitHub account ownership and publication metadata remain visible; removal of identifiers from text cannot guarantee anonymity. Do not attempt to re-identify the case.

No licence is granted over private source material. Formal research use may need clinician review, permissions and applicable ethics review.
