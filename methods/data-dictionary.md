# Evidence and data conventions

| Field | Definition |
|---|---|
| Case ID | Canine case A; public pseudonym only |
| Owner-reported | Recollection or observation supplied by owner |
| Relayed clinician finding | Owner's account of what the veterinarian said |
| Verified clinic record | Information checked against an original report; none included yet |
| Unknown | Not available; must not be encoded as normal, absent or negative |
| Relative timing | Sequence or duration, without exact calendar dates |

If results are later verified, preserve units and reference intervals in the private archive. Publish only a reviewed abstraction with relative timing. Keep the identifier mapping and detailed provenance private.
