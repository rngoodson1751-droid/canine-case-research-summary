# Public publication safeguards
This repository accepts identifier-minimised research prose only.

Exclude animal and owner names, contact details, exact birthdays and clinical dates, clinic/staff names, addresses, identifiers, signatures, billing and correspondence. Exclude photographs, raw records, ultrasound images/video, identifying overlays, EXIF/DICOM metadata and private Drive or chart links.

Use a pseudonym and relative chronology. Inspect filenames, content, commit messages/authors, issues, attachments and Git history before publication. Account ownership and GitHub timestamps are visible, so this process does not guarantee anonymity.

Never import the private repository's history or automatically synchronise it here. Stage only explicitly reviewed files. The restrictive .gitignore helps avoid accidental additions, but it is not access control: force-add and existing tracked files bypass it.

Public copies may persist in clones and caches. If sensitive content is exposed, stop publication and address history and copies. Deleting the current file alone is insufficient.

No original private veterinary document is authorised for public release by this repository.
